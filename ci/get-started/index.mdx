Setting up CI is two things: telling Trunk which repositories to collect data for, and configuring ingestion from all your CI providers. 

## Prerequisites

<Steps>
  <Step title="Connect the repository to Trunk">
    For GitHub users install the Trunk app and Trunk CI app. [See Integrating with GitHub](/setup/).

    This is what creates the repository in Trunk, and it is required even if
    your builds run on Buildkite — Trunk identifies a build's repository by its
    git remote, and collects nothing for a repository it has never seen.
  </Step>

  <Step title="Turn on CI Intelligence">
    In the Trunk app, navigate to **Settings** → **Repositories**, find
    **[your repository]**, and toggle **CI Intelligence** on.

    <Note>
      Only organization admins can change this. A member sees the toggle in its
      real state but cannot move it.
    </Note>
  </Step>
</Steps>

CI Intelligence is off by default for every repository, and turning it on
collects data from that point forward. Nothing before it is backfilled.
