Trunk integrates with GitHub through three separate apps. Install the ones you need for the products you use.

<Card title="Trunk (required)" icon="github" href="/setup/integrations/github/trunk-app" cta="permissions">
  Core integration for the Merge Queue.
</Card>

<Card title="Trunk Sudo" icon="user-shield" href="/setup/integrations/github/trunk-sudo" cta="permissions">
  Enables the Merge Queue [Direct-to-Queue](/merge-queue/using-the-queue/direct-to-queue) feature.
</Card>

<Card title="Trunk CI" icon="gears" href="/setup/integrations/github/trunk-ci" cta="permissions">
  Powers Trunk's CI Intelligence features.
</Card>

#### Permissions

Trunk only uses the permissions relevant to the tools you've enabled. For the underlying GitHub definitions, see the [**GitHub developer docs**](https://docs.github.com/en/rest/authentication/permissions-required-for-github-apps).
