## REST API Overview

Trunk provides HTTP REST APIs for each of our features. The APIs use status codes to indicate the success or failure of requests, return JSON from all requests, and use standard HTTP response codes. All API requests must be authenticated.

## Available APIs

* [Flaky Tests](../../flaky-tests/reference/api-reference): for accessing information like quarantined tests in your repo.
* [Merge Queue API (v2)](../../merge-queue/reference/api-v2): for managing merge queues, the pull requests in them, and their testing.
* [Merge Queue API (v1)](../../merge-queue/reference/merge): for existing integrations that use the organization API token.

## Authentication

The v1 APIs authenticate with your organization API token, using the header `x-api-token`. v2 API keys don't work with v1.

The v2 APIs, including the [Merge Queue API (v2)](/merge-queue/reference/api-v2) and the Flaky Tests test collection endpoints, use scoped API keys instead. See [Authentication](/merge-queue/reference/api-v2/authentication).

<Warning>
The v1 APIs will be deprecated soon. To move to v2, see [Migrate from the v1 API](/merge-queue/reference/api-v2/migrate-from-v1) for Merge Queue, and the [test collection endpoints](/flaky-tests/reference/api-reference#test-collection-endpoints) for Flaky Tests. Tools that don't accept API keys yet, including the Trunk Analytics CLI, `trunk-io/analytics-uploader`, and the Trunk MCP server's token sign-in, still need the organization API token. The [Terraform provider](/merge-queue/administration/terraform) accepts API keys from version 2.0.
</Warning>

### Finding your API token

In the Trunk app, navigate to [**Settings** → **Developer** → **API Keys**](https://app.trunk.io/settings/developer/api-tokens). Your organization API token is in the **Token** field of the **Organization API token (v1)** section.

Click the **eye icon** to reveal the token, then the **copy icon** to copy it to your clipboard. Pass it in the `x-api-token` header on any request to Trunk's v1 REST APIs.

**If you are an admin**, click **Rotate**, then **Yes, rotate token**, to replace the token. Rotating immediately invalidates the previous token, so any integrations using the old token will need to be updated. If your organization has no token yet, click **Create token**.

**If you are not an admin**, the **Rotate** button is disabled. If your organization has no token yet, ask an administrator to create one.
