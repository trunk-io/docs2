An organization admin can set defaults for CI jobs. A default fills in an option
that a job label does not set.

## The defaults

| Default  | What it sets                                              |
| -------- | --------------------------------------------------------- |
| Template | The template a job uses when its label has no `template`. |

A job label overrides a default for that job. See
[Templates and regions](/runners/actions/templates-and-regions).

## How a job resolves a template

1. The `template` value in the job's `runs-on` label, if present.
2. Your organization default template, if set.
3. No template. The job runs on the default Trunk runner image, which contains
   most of the GitHub Actions `ubuntu-latest` image.

<Info>
  A default is optional. Set one when most of your jobs use the same template,
  and keep the per-job `template` option for jobs that need a different one.
</Info>
