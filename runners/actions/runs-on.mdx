You point a job at Trunk Runners with one `runs-on` label.

```yaml
runs-on: trunk=${{ github.run_id }}-${{ github.run_attempt }}
```

## Options

| Option     | Required | What it sets                                                                                                            |
| ---------- | -------- | ----------------------------------------------------------------------------------------------------------------------- |
| `size`     | No       | The machine size, which sets the CPU count. See [Machine sizes](/runners/actions/sizes).                                |
| `memory`   | No       | The memory per CPU: `low`, `standard`, or `high`. <br />See [Machine sizes](/runners/actions/sizes#sizes).              |
| `template` | No       | The template (a prepared environment) for the job. See [Templates and regions](/runners/actions/templates-and-regions). |
| `cache`    | No       | `trunk` or `github` to choose the cache for `actions/cache`. See [Caching](/runners/cache/index).                       |

## Examples

A large runner with high memory:

```yaml
runs-on: trunk=${{ github.run_id }}-${{ github.run_attempt }}..size=large..memory=high
```

A large runner with low memory, for a job that needs CPUs but little memory:

```yaml
runs-on: trunk=${{ github.run_id }}-${{ github.run_attempt }}..size=large..memory=low
```

A job on a chosen template:

```yaml
runs-on: trunk=${{ github.run_id }}-${{ github.run_attempt }}..size=medium..template=<template-id>
```

See the [full label format](/runners/reference/runs-on-grammar) for every option in
one table.
