You point a job at Trunk Runners with one `runs-on` label.

```yaml
runs-on: trunk=${{ github.run_id }}-${{ github.run_attempt }}..size=medium
```

## Options

| Option | Required | What it sets |
| --- | --- | --- |
| `size` | Yes | The machine size, which sets the CPU count. See [Machine sizes](/runners/actions/sizes). |
| `memory` | No | `high` for 4 GiB per CPU instead of 2. <br />See [Machine sizes](/runners/actions/sizes). |
| `template` | No | The template (a prepared environment) for the job. See [Templates and regions](/runners/actions/templates-and-regions). |
| `cache` | No | `trunk` or `github` to choose the cache. See [Caching](/runners/cache/index). |

## Examples

A medium runner with high memory:

```yaml
runs-on: trunk=${{ github.run_id }}-${{ github.run_attempt }}..size=large..memory=high
```

A job on a chosen template and region:

```yaml
runs-on: trunk=${{ github.run_id }}-${{ github.run_attempt }}..size=medium..template=<template-id>..region=us-west
```

See the [full label format](/runners/reference/runs-on-grammar) for every option in one table.
