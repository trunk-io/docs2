This page lists every option of the Trunk Runners `runs-on` label in one place.
For a guide with more context, see [The runs-on label](/runners/actions/runs-on).

## Format

```text
trunk=<run>[..size=<size>][..memory=<value>][..template=<id>][..region=<name>][..cache=<value>][..run-as=<mode>]
```

- `trunk=<run>` — the anchor. Use `${{ github.run_id }}-${{
github.run_attempt }}` for `<run>`, so a job from a different workflow run
  cannot take this run's runners.
- `..` joins the options.
- Each option is `key=value`.

## Options

| Option     | Required | Values                | Default                                                                                               |
| ---------- | -------- | --------------------- | ----------------------------------------------------------------------------------------------------- |
| `size`     | No       | See [Sizes](#sizes)   | `small`                                                                                               |
| `memory`   | No       | See [Memory](#memory) | See [Memory](#memory)                                                                                 |
| `template` | No       | A template ID         | Organization default                                                                                  |
| `region`   | No       | A region name         | See [How a job resolves a region](/runners/actions/templates-and-regions#how-a-job-resolves-a-region) |
| `cache`    | No       | `trunk`, `github`     | `trunk`, per your settings                                                                            |
| `run-as`   | No       | `dispatcher`, `actor` | Off                                                                                                   |

### Sizes

The memory columns are the values of the `memory` option.

| `size`   | CPUs | `low`  | `standard` (default with a `size`) | `high`                      |
| -------- | ---- | ------ | ---------------------------------- | --------------------------- |
| `xsmall` | 1    | 1 GiB  | 2 GiB                              | 4 GiB                       |
| `small`  | 2    | 2 GiB  | 4 GiB                              | 8 GiB (the default machine) |
| `medium` | 4    | 4 GiB  | 8 GiB                              | 16 GiB                      |
| `large`  | 8    | 8 GiB  | 16 GiB                             | 32 GiB                      |
| `xlarge` | 16   | 16 GiB | 32 GiB                             | 64 GiB                      |

### Memory

| `memory`   | Memory per CPU |
| ---------- | -------------- |
| `low`      | 1 GiB          |
| `standard` | 2 GiB          |
| `high`     | 4 GiB          |

The default `memory` depends on `size`. With no `size`, the default is `high`, which
gives the [default machine](/runners/actions/sizes#the-default-machine). With a
`size`, the default is `standard`.

## Rules

- The order of the options does not matter.
- A key must not repeat.
- The `trunk=` label must be the only label in `runs-on`.
- A label that breaks one of these rules gets no runner. The job stays queued, and
  Trunk gives you no message.

## Examples

The default machine, 2 CPUs and 8 GiB:

```yaml
runs-on: trunk=${{ github.run_id }}-${{ github.run_attempt }}
```

A medium runner:

```yaml
runs-on: trunk=${{ github.run_id }}-${{ github.run_attempt }}..size=medium
```

A large runner with high memory, a chosen template, and the shared cache:

```yaml
runs-on: trunk=${{ github.run_id }}-${{ github.run_attempt }}..size=large..memory=high..template=<template-id>..cache=trunk
```
