This page lists every option of the Trunk Runners `runs-on` label in one place. For a guide with more context, see [The runs-on label](/runners/actions/runs-on).

## Format

```text
trunk=<run>..size=<size>[..memory=<value>][..template=<id>][..region=<name>][..cache=<value>][..run-as=<mode>]
```

- `trunk=<run>` — the anchor. Use `${{ github.run_id }}-${{
  github.run_attempt }}` for `<run>`, so each job keeps its own runner.
- `..` joins the options.
- Each option is `key=value`.

## Options

| Option | Required | Values | Default |
| --- | --- | --- | --- |
| `size` | Yes | `xsmall`, `small`, `medium`, `large`, `xlarge` | None |
| `memory` | No | `standard`, `high` | `standard` |
| `template` | No | A template ID | Organization default |
| `region` | No | A region name | Organization default |
| `cache` | No | `trunk`, `github` | On, per your settings |
| `run-as` | No | `dispatcher`, `actor` | Off |

## Rules

- The order of the options does not matter.
- Keys are not case-sensitive.
- A key must not repeat.
- A wrong or unknown key fails the job with a clear message.

## Examples

A medium runner:

```yaml
runs-on: trunk=${{ github.run_id }}-${{ github.run_attempt }}..size=medium
```

A large runner with high memory, a chosen template, and the Trunk cache:

```yaml
runs-on: trunk=${{ github.run_id }}-${{ github.run_attempt }}..size=large..memory=high..template=<template-id>..cache=trunk
```
