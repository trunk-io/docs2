## Coming soon

<CardGroup cols={2}>
  <Card title="Buildkite on Kiln" icon="box">
    Run your Buildkite jobs on the same Trunk runners. You target a Kiln queue
    and set the size, template, and region with agent tags.
  </Card>
  <Card title="Runners for public repositories" icon="globe">
    Serve public repositories on a hardened runner, so you can run CI on open
    repositories with the right guardrails.
  </Card>
  <Card title="Cache visibility" icon="database">
    See and clear your cache entries. View the size, the age, and the usage of
    your cache.
  </Card>
  <Card title="Workflow migration" icon="git-pull-request">
    Trunk opens a pull request that moves your existing jobs onto Kiln, so you
    do not edit each workflow by hand.
  </Card>
  <Card title="Agent CI" icon="robot">
    Start a coding agent from a comment on GitHub or Slack. The agent works in a
    Trunk workspace.
  </Card>
</CardGroup>
