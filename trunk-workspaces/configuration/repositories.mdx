Organization admins and owners can choose the workspace configuration used when a
repository launches a Trunk Workspace.

Navigate to **Settings** → **Organization** → **Repositories**.

1. Set an organization-wide template and size for repositories without an explicit
   mapping.
2. Search for a repository visible to the installed Trunk GitHub App.
3. Select a repository-specific template and size when it needs different defaults.
4. Save the mapping.

Members can inspect the mappings but cannot change them. A repository may appear as
unavailable when the GitHub installation can no longer access it; update the GitHub
App installation before changing that repository's mapping.

This page documents the workspace configuration selected by the trunk app. CI runner
installation and operation are outside the scope of Trunk Workspaces documentation.
