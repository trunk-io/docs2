AWS connectors grant selected workspace templates access to customer-managed AWS
roles through an organization proxy. Creating, editing, rotating, attaching, or
deleting these resources requires an organization admin or owner.

## Add a proxy

1. Navigate to **Settings** → **Organization** → **AWS**.
2. Click **Add proxy**.
3. Enter a name, HTTPS endpoint, region, and the proxy's own AWS role.
4. Click **Create**.
5. Copy the introspection secret from the next screen and store it securely. The app
   shows this value only when it is created or rotated.

## Add a connector

1. From **Settings** → **Organization** → **AWS**, click **Add connector**.
2. Select an existing proxy.
3. Enter a connector name and the AWS role ARN that workspaces may assume.
4. Click **Create**.
5. Open an organization template and attach the connector with its desired AWS
   profile name.

<Warning>
  Rotating a proxy secret invalidates the previous secret. Update the
  customer-side proxy before relying on new workspace sessions.
</Warning>

Deleting a proxy also deletes its connectors. Remove connector attachments from
templates and confirm that no workspace setup still depends on them first.
