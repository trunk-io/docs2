Templates define repeatable workspace setup. They can provide startup and refresh
scripts, environment variables, exposed ports, included templates, a default working
directory, and attached AWS connectors.

## Organization templates

Navigate to **Settings** → **Organization** → **Templates**.

- Click **New template** to create a reusable setup for the organization.
- Select a template to inspect, edit, delete, or set it as the default for manually
  created workspaces.
- Attach available AWS connectors and choose the profile name exposed inside a
  workspace. Attaching or removing organization AWS access requires an organization
  admin or owner.

When one template includes another, the app resolves the shared setup before the
selected template's own commands.

## Personal template

Navigate to **Settings** → **User** → **Template** to configure setup that applies
only to workspaces you create in the selected organization. The personal startup
script runs after the organization template.

<Note>
  Template changes apply during a later workspace startup. They do not rewrite
  the environment of an already-running workspace.
</Note>
