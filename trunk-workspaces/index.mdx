<Warning>
  Trunk Workspaces is in private beta. Its workflows and available integrations
  may change between releases.
</Warning>

Trunk Workspaces gives you an isolated cloud development environment with a coding
agent, terminal access, persistent files, and shareable HTTP services. You manage
the workspace from the trunk desktop app while its compute runs remotely.

Use Trunk Workspaces to:

- Create a workspace from an organization template.
- Work with a coding agent and multiple terminal tabs.
- Open the workspace in VS Code, Cursor, or Zed.
- Expose an HTTP port and forward it to localhost.
- Stop or sleep compute while retaining the workspace disk.
- Share a running workspace with another organization member.
