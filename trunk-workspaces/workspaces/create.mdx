You can create a workspace from the empty state or from the **Add workspace** button
in the sidebar.

<Steps>
  <Step title="Open the creation dialog">Click **Add workspace**.</Step>
  <Step title="Choose the workspace settings">
    Enter an optional name, then select a template, region, size, and coding
    agent. The available choices come from your organization and the current
    deployment.
  </Step>
  <Step title="Create the workspace">
    Click **Create**. The workspace appears immediately while its sandbox is
    being provisioned.
  </Step>
  <Step title="Wait for the workspace to become ready">
    The app opens the workspace when the remote sandbox is reachable. You can
    move elsewhere in the app while provisioning continues.
  </Step>
</Steps>

<Frame caption="Choose the workspace template, region, and size.">
  ![The Create New Workspace
  dialog.](/assets/trunk-workspaces/create-workspace.png)
</Frame>

An organization template defines the shared startup script, environment variables,
default ports, and optional working directory. Your personal template runs after
the organization template for every workspace you create in that organization.

See [Templates](/trunk-workspaces/configuration/templates) to manage those defaults.
