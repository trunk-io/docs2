Open the **Agent** tab to work with a coding agent inside the selected workspace.
The agent operates on the workspace files and keeps running when you switch tabs or
move to another workspace.

## Start a session

1. Open the **Agent** tab.
2. Select an available agent when the workspace has no active session.
3. Enter your request and send it.
4. Respond when the agent asks for permission or additional information.

You can attach files or paste images into the composer. On supported desktop builds,
use the microphone button to dictate a prompt.

## Manage sessions

The session list appears when a workspace has multiple rooms. Owners can create,
switch, and delete sessions. Session connections remain active while their chat view
is closed, so attention requests can still raise a desktop notification.

## Collaborate in a shared workspace

A person viewing a workspace shared with them can join the owner's active agent
rooms and collaborate in the conversation. A shared viewer cannot create or delete
rooms, start the sandbox, or originate a session. If the workspace is stopped, ask
the owner to resume it.
