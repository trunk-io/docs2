The **Agent** tab is a frontend for a coding-agent CLI that runs inside your
workspace. The agent works on the workspace files. It keeps running when you switch
tabs or move to another workspace.

## Authenticate the agent

The agent uses the same credentials as the CLI. You log it in the same way you
would on your own machine.

<Steps>
  <Step title="Open the Terminal tab">
    Select the **Terminal** tab in the workspace.
  </Step>
  <Step title="Run the agent CLI">
    Start the agent CLI in the terminal, for example `claude`. Complete its
    normal login, such as the OAuth step, exactly as you do on your own machine.
  </Step>
  <Step title="Use the Agent tab">
    Open the **Agent** tab. It reuses the credential you created in the
    terminal, so it is ready to work.
  </Step>
</Steps>

<Note>
  The Agent tab does not have its own account login. You log the agent in from
  the terminal. Connecting an MCP server is separate, and you do that from the
  Agent tab's Info drawer.
</Note>

## Start a session

1. Open the **Agent** tab.
2. Select an available agent when the workspace has no active session.
3. Enter your request and send it.
4. Respond when the agent asks for permission or more information.

You can attach files or paste images into the composer. On supported desktop
builds, use the microphone button to dictate a prompt.

## Use the terminal

The **Terminal** tab opens a shell in the workspace. Terminal sessions live in the
remote sandbox and reconnect after you navigate away or restart the app.

- Create, rename, reorder, and close terminal tabs from the tab strip.
- Drag files into the workspace to upload them to the active terminal's working
  directory.
- The terminal is where you log the agent CLI in, as shown above.
