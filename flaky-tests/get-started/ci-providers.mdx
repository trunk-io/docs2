---
title: "CI Providers"
description: "You can easily integrate Flaky Tests from any CI Provider"
---
Trunk Flaky Tests integrates with your CI by adding a `Upload Test Results` step in each of your testing CI jobs via the [Trunk CLI](/flaky-tests/uploader). See the [Test Frameworks](/flaky-tests/get-started/frameworks) docs for instructions on producing test reports for your test runner, which Trunk can ingest.

<Warning>
**Not using GitHub for source control?**

Flaky Test support for source control providers like GitLab and BitBucket is still experimental. If you're using a source control provider other than GitHub, [**contact us**](mailto:support@trunk.io) **to get started**.
</Warning>
