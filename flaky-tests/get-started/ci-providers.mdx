---
title: "CI Providers"
mode: wide
description: "You can easily integrate Flaky Tests from any CI Provider"
og:title: "CI providers supported by Trunk Flaky Tests"
---
Trunk Flaky Tests integrates with your CI by adding a `Upload Test Results` step in each of your testing CI jobs via the [Trunk Analytics CLI](/flaky-tests/reference/cli-reference). See the [Test Frameworks](/flaky-tests/get-started/frameworks) docs for instructions on producing test reports for your test runner, which Trunk can ingest.

<Info>
**Not using GitHub for source control?**

Flaky Test support for source control providers like GitLab and BitBucket is still experimental. If you're using a source control provider other than GitHub, [**contact us**](mailto:support@trunk.io) **to get started**.&#x20;
</Info>
