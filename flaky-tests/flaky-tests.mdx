The Trunk Flaky Tests API provides access to check the status of Trunk services and fetch [unhealthy](/flaky-tests/detection) or [quarantined](/flaky-tests/quarantining) tests in your project. The API is an HTTP REST API, returns JSON from all requests, and uses standard HTTP response codes.

All requests must be [authenticated](/setup-and-administration/apis#authentication) by providing the `x-api-token` header.
