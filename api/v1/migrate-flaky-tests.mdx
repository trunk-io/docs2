The legacy Flaky Tests endpoints (`/v1/flaky-tests/*`) were scoped to a repository, and they are retired along with repository-scoped Flaky Tests. They still accept requests but no longer return results. Use the API's [test collection](/flaky-tests/test-collections) endpoints instead.

The two scopes are separate APIs, not two versions of one API. So not every legacy endpoint has an equivalent with the same shape.

## What changes

- **Credential.** The legacy API uses the organization API token in `x-api-token`. The API uses an [API key](/api/authentication#api-keys) in `Authorization: Bearer <key>`. Any API key can call the Flaky Tests endpoints. They need no [permission](/api/authentication#permissions).
- **Base URL.** Legacy paths go after `https://api.trunk.io/v1`. API paths already start with `/v2`, so they go after `https://api.trunk.io`.
- **Method.** Legacy endpoints are `POST` with a JSON body. API reads are `GET` with query parameters.
- **Lists.** API lists are [paginated](/api/pagination) with cursors.
- **Errors.** API errors use the [error envelope](/api/errors#error-envelope). Switch on `error.code`.

## Endpoint map

| If you want to | Retired legacy endpoint | Endpoint to use |
|---|---|---|
| Read one test | `POST /flaky-tests/get-test-details` | [Get a test](/api/tests/get-a-test) |
| Find unhealthy tests | `POST /flaky-tests/list-unhealthy-tests` | [List and search tests](/api/tests/list-and-search-tests), filtered by status |
| Find quarantined tests | `POST /flaky-tests/list-quarantined-tests` | [List and search tests](/api/tests/list-and-search-tests), filtered by quarantine state |
| Find recent failures | `POST /flaky-tests/list-failing-tests` | [List a test's runs](/api/tests/list-a-tests-runs) |
| Link a ticket to a test | `POST /flaky-tests/link-ticket-to-test-case` | [Link a ticket to a test](/api/tests/link-a-ticket-to-a-test) |
| File a new ticket for a test | *Not applicable* | [Create a ticket for a test](/api/tests/create-a-ticket-for-a-test) |
| List or create collections | *Not applicable* | [List](/api/testcollections/list-test-collections) / [Create a test collection](/api/testcollections/create-a-test-collection) |

<Note>
A test's ID in a collection is not the ID the legacy endpoints returned, so an ID stored from a legacy endpoint can't be passed to a collection endpoint. The repository's `repository.id` is the only identifier the two share.
</Note>

Tools that don't accept API keys yet, including the Trunk Analytics CLI, `trunk-io/analytics-uploader`, and the Trunk MCP server's token sign-in, still need the organization API token.
