## Prerequisites

After you complete the configuration, check that:

- The GitLab connection shows as connected in **Settings** → **Integrations** → **GitLab**
- The project has a webhook named `Trunk` in **Settings** → **Webhooks**
- The service account can merge into your target branch
- No protected branch rule or push rule blocks `trunk-merge/**` branches
- The project's merge method is **Merge commit**
- Your pipelines run on merge requests from `trunk-merge/` branches
- The queue has at least one required status

## Test your configuration

1. Open a test merge request against your target branch.
2. Add a comment on the merge request: `/trunk merge`. You need at least the **Developer** role on the project to submit.
3. Check the [Trunk dashboard](https://app.trunk.io/) to follow the merge request.
4. The merge request shows as **Not Ready** until GitLab reports it as ready to merge.
5. Click the merge request in the dashboard to see what it is waiting for.
6. Trunk also posts a status comment on the merge request and updates it as the merge request moves through the queue.

**Expected behavior:** a draft merge request labeled `trunk-merge-queue-test-run` opens, its pipeline runs, and Trunk merges your merge request when the required statuses pass.

### Other ways to submit

- **Label:** add the queue's [enqueueing label](/merge-queue/administration/advanced-settings#enqueueing-label) (`trunk-merge-queue-submit` by default). Remove the label to cancel.
- **Checkbox:** check the box in Trunk's comment on the merge request.
- **Web app** and **[API](/merge-queue/using-the-queue/api)**.
- **[CLI](/merge-queue/reference/merge-queue-cli-reference):** pass the merge request's URL.
- **[Browser extension](/merge-queue/browser-extensions):** shows a merge queue card on GitLab.com merge request pages.

To cancel, comment `/trunk cancel`.

## Troubleshooting

<Info>
  Visit [Trunk Support](/setup-and-administration/support) for more help or to contact the support team.
</Info>

- **Stuck in "Not Ready":** GitLab doesn't report the merge request as ready to merge. Check the merge request widget for missing approvals, unresolved threads, a failed or running pipeline, draft status or conflicts. If the merge request needs a rebase, change the project's merge method to **Merge commit** (see [Merge method](/merge-queue/getting-started/gitlab/configure-project-settings#merge-method)).
- **Fails right after testing starts with a push error:** a protected branch rule or push rule blocks `trunk-merge/**`. GitLab's message is "You are not allowed to push code to protected branches on this project" or "You are not allowed to push code to this project". See [Test branches](/merge-queue/getting-started/gitlab/configure-project-settings#test-branches) and [Push rules](/merge-queue/getting-started/gitlab/configure-project-settings#push-rules).
- **Fails with "required statuses are not defined":** the queue has no required statuses. See [Set required statuses](/merge-queue/getting-started/gitlab/configure-ci-pipelines#set-required-statuses).
- **Testing never finishes:** no pipeline reported a required job on the draft merge request, so the test run fails at the queue's [testing timeout](/merge-queue/administration/advanced-settings#timeout-for-tests-to-complete) (5 hours by default). Check that your `workflow: rules` allow `trunk-merge/` branches, that each required status matches a job name exactly, and that no required job is a manual job waiting to be run.
- **Fails when attempting to merge:** check that the service account is in **Allowed to merge** on the target branch, that the queue's merge method isn't **Rebase**, and that the project's squash option allows the queue's [merge method](/merge-queue/getting-started/gitlab/configure-project-settings#squash-commits-when-merging).
- **Nothing happens when you comment `/trunk merge`:** check that:
  - The merge request targets a branch that has a queue.
  - The `Trunk` webhook is enabled in the project's **Settings** → **Webhooks**.
  - You have at least the **Developer** role on the project.
  - Comment commands are turned on in the queue's settings. If they are off, Trunk replies "Trunk commands via comments are disabled for this merge queue."
- **The queue stopped merging everything:** check the connection in **Settings** → **Integrations** → **GitLab**. A revoked or expired token, or a service account that lost the Maintainer role, stops the queue.
