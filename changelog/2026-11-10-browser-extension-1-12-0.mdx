**Version 1.12.0 of the Trunk browser extension supports GitHub's new pull request Overview page.**

GitHub is rolling out a redesigned pull request page, the [Overview page](https://github.blog/changelog/2026-11-05-new-pull-request-overview-page-in-public-preview/), in public preview. The extension now works on it:

- **Merge queue card**: The Trunk merge queue card appears as its own row in the summary box, below GitHub's **Recommended action** row. It replaces GitHub's merge button, and **View merge status** stays where it is.
- **Merge status panel**: When you open GitHub's **Merge status** panel, the card moves into the panel, as it already did on the classic page.
- **Status pill**: The Trunk queue status shows on the pull request's header line.
- **Test results**: The Trunk test results panel appears in the right-hand sidebar, below **Labels**.

The classic pull request page works as before. You can switch between the two pages from the pull request header while GitHub's preview runs.

The extension auto-updates through the Chrome Web Store and Firefox Add-ons. To check your installed version, open the extension popup and look under **Settings**.
