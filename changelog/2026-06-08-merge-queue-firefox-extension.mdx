**The Trunk browser extension now has Firefox support.**

A Firefox build now ships alongside the existing Chrome build:

- **Live on Firefox Add-ons.** Install [Trunk for GitHub](https://addons.mozilla.org/en-US/firefox/addon/trunk-for-github/) straight from the Mozilla Add-ons store.
- **Full feature parity with Chrome.** The Firefox build supports all merge queue controls: submit, cancel, resubmit, real-time status updates, and row hiding.
- **Firefox 140+ on desktop, 142+ on Android.** The extension uses Manifest V3 with a Firefox-compatible background script configuration.

[Read the docs](https://docs.trunk.io/merge-queue/browser-extensions) for install instructions and more information.
