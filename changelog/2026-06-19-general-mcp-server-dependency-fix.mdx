**The Trunk MCP server is fully operational again.**

The underlying adapter package (`@vercel/mcp-adapter`) was deprecated by Vercel. This update migrates to its replacement (`mcp-handler`), restoring MCP connectivity for all clients.

No configuration changes are required. If you were seeing errors when connecting an MCP client to Trunk, reconnecting should now work.

[Read the docs](https://docs.trunk.io/flaky-tests/mcp-tools) to learn more.
