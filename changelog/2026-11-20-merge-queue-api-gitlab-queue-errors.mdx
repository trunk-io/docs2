**The v2 API now tells you plainly when a Merge Queue endpoint doesn't serve GitLab queues yet.**

### Updates

- **Clear error for GitLab merge queues.** [List a merge queue's pull requests](/api/mergequeues/list-a-merge-queues-pull-requests) and [list a merge queue's verification runs](/api/mergequeues/list-a-merge-queues-verification-runs) now return `422 MERGE_QUEUE_FORGE_NOT_SUPPORTED` when the queue is on GitLab. Switch on the `code` to handle it. See [Errors](/api/errors).

See the [API reference](/api) for all v2 endpoints.
