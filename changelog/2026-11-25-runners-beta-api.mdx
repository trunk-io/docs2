**You can now manage Trunk Runners through the API, not only from the web app.** The Runners API is in beta at `https://api.trunk.io/v2beta/runners`. Authenticate with the `x-trunk-token` header. Trunk Runners is in private beta. Contact [support@trunk.io](mailto:support@trunk.io) to join.

### New features

- **Usage and live runners.** Read your organization's runner usage, list the runners running now, and get measurements for CI jobs.
- **CI jobs.** Get a CI job's log and its runner metrics.
- **Cache.** Read cache usage for your organization or a repository, list a repository's cache entries and evictions, and purge a repository's cache. Set or reset a repository's cache setting. See [Caching](/runners/cache/index).
- **Templates.** Create, edit, publish and delete [templates](/runners/actions/templates). List template builds, read build logs, and rebuild, roll back or end a release hold in a region.
- **CI configuration.** Read and update your CI configuration, list the regions CI can use, and set a CI region per repository.
- **Runner groups.** List runner groups and the repositories that use each one.

See the Runners section of the [API reference](/api) for every endpoint.
