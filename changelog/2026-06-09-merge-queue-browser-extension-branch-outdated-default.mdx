**The 'Branch out of date' row hiding toggle now defaults to off on fresh installs.**

When the 0.8.0 row hiding feature shipped, all three hide toggles defaulted to on. User feedback showed that hiding the "This branch is out-of-date with the base branch" row by default was unexpected: some teams rely on that row to know a rebase is needed before merging.

The toggle default has been changed:

| Toggle | Previous default | New default |
| --- | --- | --- |
| **Merging is blocked** | On (hidden) | On (hidden) |
| **Branch out of date** | On (hidden) | Off (visible) |
| **Trunk (bot) GitHub Comments** | On (hidden) | On (hidden) |

This change affects new installs and users who have never explicitly set this preference. Existing users who already toggled the setting keep their saved preference unchanged.

To show or hide the row, click the Trunk toolbar icon, open **Settings**, and find the **Hide rows** card. See [Configuring row hiding](https://docs.trunk.io/merge-queue/browser-extensions#configuring-row-hiding) for details.
