We’ve updated the Merge Queue **Failure** tab so that only PRs that failed and have not been
resubmitted to the queue are displayed.

Previously, the **Failure** tab contained a list of all historical PR failures, making it difficult
to identify current failures requiring action. This change gives you a concise list of PR failures
that can be fixed and resubmitted to the queue. Upon resubmission, the PR is removed from the page.
