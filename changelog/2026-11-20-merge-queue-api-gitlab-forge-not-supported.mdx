**The v2 API now tells you clearly when a merge queue endpoint doesn't serve GitLab yet.**

### Updates

- **New `MERGE_QUEUE_FORGE_NOT_SUPPORTED` error.** [List a merge queue's pull requests](/api/mergequeues/list-a-merge-queues-pull-requests) and [list a merge queue's verification runs](/api/mergequeues/list-a-merge-queues-verification-runs) return `422 MERGE_QUEUE_FORGE_NOT_SUPPORTED` when the queue is on GitLab. Sending the same request again returns the same response, so don't retry it.

See [Status codes and errors](/api/errors#error-codes) for every error code.
