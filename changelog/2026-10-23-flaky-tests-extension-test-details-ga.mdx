**The test details panel in the Trunk browser extension is now on for everyone.**

### Updates

- **No opt-in needed.** You no longer need to contact support to turn on the panel. It appears automatically on GitHub pull request pages for any repository with [Flaky Tests uploads](/flaky-tests/overview).
- **Test results on the PR page.** The **Test Results** panel shows pass, fail, quarantined, and flaky counts for the head commit. It links straight into the Flaky Tests dashboard.
- **Compare commits.** Use the commit history dropdown to check a new failure against the previous commit's results.
- **Tests tab.** The extension popup lists repositories with test uploads and links to each in the Flaky Tests app.

Repositories without test uploads are unaffected.

See the [test details panel docs](/merge-queue/browser-extensions#test-details-panel) to learn more, or [install the extension](/merge-queue/browser-extensions#install-the-extension) to get started.
