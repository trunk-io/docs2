**Trunk CLI 1.29.0 is available now.** Run `trunk upgrade` to get it.

**🔒 Security**

- Upgraded libgit2 to [v1.9.7](https://github.com/libgit2/libgit2/releases/tag/v1.9.7), the latest stable release.
- Upgraded bundled libraries.

**✨ Improvements**

- `trunk init` always writes a `plugins:` section. Each release includes the latest [trunk-io/plugins](https://github.com/trunk-io/plugins) version, which init uses if it can't look up the newest one.
- The minimum trunk-io/plugins version is now v1.10.0, which brings Ruby 3.4 and Python 3.14 runtimes. `trunk upgrade` updates older pinned refs.
- CI detection now covers Bamboo, Google Cloud Build, GoCD, Harness, TaskCluster, Prow, Codefresh, Buddy, Screwdriver and Vela. `CI=false` now means "not CI".

**🕵️ Privacy**

- The CLI no longer sends telemetry from CI.
- Usage analytics are limited to six events: `check`, `fmt`, `init`, `upgrade`, `merge` and `merge status`. The CLI no longer sends identify calls, so it sends no name or email.
- Removed Sentry, Mixpanel and LaunchDarkly from the CLI.

**⚠️ Behavior changes**

- `s3://` downloads in `trunk.yaml` now need a public bucket. The CLI no longer reads your AWS `default` profile.
- Removed the hidden `trunk flare` command.
