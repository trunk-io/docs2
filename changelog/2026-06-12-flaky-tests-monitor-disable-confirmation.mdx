title: "Flaky Tests: Confirmation Dialog Before Disabling a Monitor"
description: "Disabling a monitor now shows a confirmation dialog that describes what will happen to affected tests before the change takes effect."
date: 2026-06-12
category: Flaky Tests
type: update
---

**Disabling a monitor from the Monitors page now requires confirmation before the change takes effect.**

When you select **Disable** from a monitor's context menu, a dialog appears summarizing what the disable will do to affected tests, before the change fires. The message is tailored to the monitor's configured action:

- If the monitor classifies tests (flaky or broken), the dialog explains that any tests currently classified by this monitor will recover.
- If the monitor applies labels, the dialog explains that the labels it applied will be removed.

You can still re-enable a disabled monitor at any time. The dialog includes a reminder of this.

The delete confirmation dialog has also been updated to show the same action-specific consequences, replacing the previous generic message.

This confirmation step prevents accidental disables from a mis-click, especially on monitors that are actively classifying a large number of tests.
