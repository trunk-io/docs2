**The Trunk browser extension now has Firefox support.**

A Firefox build has been added alongside the existing Chrome build and validated against Mozilla Add-ons (AMO) requirements:

- **Full feature parity with Chrome.** The Firefox build supports all merge queue controls: submit, cancel, resubmit, real-time status updates, and row hiding.
- **Manifest V3 with Firefox compatibility.** The extension uses a Firefox-compatible background script configuration, with minimum versions of Firefox 140 on desktop and Firefox 142 on Android.
- **AMO listing coming soon.** The build has passed AMO validation. The public Firefox Add-ons listing is being finalized. In the meantime, developers can load the build as a temporary add-on in Firefox Developer Edition or Nightly.

[Read the docs](https://docs.trunk.io/merge-queue/chrome-extension) for install instructions and more information.
