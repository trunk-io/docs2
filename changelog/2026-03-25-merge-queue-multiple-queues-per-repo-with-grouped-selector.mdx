**You can now run multiple merge queues in the same repository, each targeting a different branch.**
Previously, a repo could only have one queue. Now you can create additional queues from the merge
queue creation page. The repo selector shows repos that already have queues and how many exist. The
settings page supports switching between queues via a branch selector with colored state indicators
(green = Running, yellow = Paused). The dashboard selector groups repos with multiple queues so you
can tell them apart at a glance.
