Trunk Merge Queue now supports automatically setting the required status checks by scanning the
GitHub branch protection of the target branch. See
[Define Required Status For Testing](https://docs.trunk.io/merge/set-up-trunk-merge#define-required-status-checks-for-testing)
for details.
